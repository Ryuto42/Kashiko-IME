## Kashiko IME とは

Kashiko IME は、macOS環境向けに最適化された次世代の日本語入力システム（IME）です。
最新のニューラルネットワーク技術（GPT-2ベースのモデル + llama.cpp）を活用し、文脈を考慮した自然で高度な日本語変換を実現します。さらに、リアルタイムで変換候補を表示する「ライブ変換」機能や、ユーザーの入力傾向を学習する機能を備えています。

### 主な特徴

- **ニューラルかな漢字変換**: 従来の辞書ベースの変換だけでなく、文脈を理解するAIモデルによる高精度な変換。
- **ライブ変換**: 入力と同時に自動で変換結果を画面上に表示。スペースキーを押す回数を劇的に減らします。
- **文脈学習・予測変換**: ユーザーが過去に選択した候補を学習し、次回の入力時から数文字打つだけで予測候補として提示します。誤変換やスペルミスに由来する意味の取れない学習は自動的に除外され、極端に長い文章は学習・候補表示の対象外になります。
- **高度なフォーマッター**: 半角カタカナ、全角英数、各種記号、16進数など、多様な表記バリエーションを自動生成します。
- **長文入力の最適化**: ライブ変換で使ったチャンク単位の変換結果を再利用することで、スペースキー押下時の再変換コストを削減。入力途中でスペルミスがあっても、変換に失敗した箇所の手前まではきれいに変換し、以降は未変換のまま残して再入力しやすくします。

## インストール方法

本プロジェクトをご自身のMacでビルド・インストールする手順です。

### 前提条件
- macOS 13 (Ventura) 以降
- Xcode または Swift コマンドラインツール
- Rust ツールチェーン (`cargo` コマンドが使用できる状態)
- GNU Make

### ビルドとセットアップ

1. **リポジトリのクローン**
   ```bash
   git clone https://github.com/Ryuto42/Kashiko-IME.git
   cd Kashiko-IME
   ```

2. **ビルドとインストール**
   macOS向けのビルドスクリプトを実行します。
   ```bash
   cd kashiko-macos
   make install
   ```
   *※初回ビルド時はRustのコンパイルやHugging FaceからのAIモデル（GGUFファイル）のダウンロードが行われるため、数分〜数十分の時間がかかります。*

3. **IMEの有効化**
   - インストールが完了したら、一度Macから**ログアウトして再度ログイン**するか、Macを再起動してください。
   - `システム設定` > `キーボード` > `テキスト入力` の `入力ソース` > `編集` を開きます。
   - 左下の `+` ボタンを押し、「日本語」の中から **Kashiko** を追加してください。

## 技術的な詳細

Kashiko IMEは、Rustで書かれた高速なバックエンドエンジンと、Swiftで書かれたmacOSネイティブなフロントエンド（InputMethodKit）から構成されています。

- **`kashiko-im` (Rust)**: 変換エンジンのコア。入力ステートマシン、ローマ字からひらがなへの変換、学習データの管理、かな漢字変換APIの呼び出しを担います。
- **`kashiko-engine` (Rust)**: llama.cppのバインディングを使用し、ローカル上でAI言語モデルを推論させることで高精度な変換を実現します。
- **`kashiko-macos` (Swift)**: macOSのInputMethodKit (IMK) を用いたUI実装。RustバックエンドとはJSON-RPCを介して通信します。

## プライバシーとセキュリティ

Kashiko IME はローカル完結で動作し、入力内容や学習データを外部に送信することはありません。

- **辞書・学習データ**: ユーザー辞書は `~/.local/share/kashiko-im/user_dicts/`、変換学習キャッシュは `~/.local/share/kashiko-im/learning.tsv` にのみ保存され、すべて端末内で完結します。
- **AIモデルによる変換**: かな漢字変換は `llama.cpp` によるローカル推論で行われ、入力テキストが外部サーバーに送信されることはありません。
- **ネットワーク通信が発生するタイミング**: 初回ビルド時のみ、Hugging Face から GGUF モデルおよびシステム辞書をダウンロードします（`kashiko-engine/src/kanji/hf_download.rs`）。それ以外の通常利用時に外部通信は行いません。
